notes

how to read the 'kind' column
  measured      an observation taken from the running cluster in this run
  derived       arithmetic over this run's measurements (a ratio, a percentile)
  assumed       a value this tool was told, not something it checked
  not-measured  this run produced no evidence; the target column still shows
                what the design document asks for, and the value column is empty
