What this page does not show

  1. Nobody labelled these pairs. They were generated by construction (no human labelled these pairs): two phrasings written from one itinerary record are called the same request, two phrasings from different records are called different requests. Where that assumption is wrong, the accuracy figures are wrong by the same amount and in the same direction. A result fit to publish needs a person to read real retry pairs, decide each one, and a second person to do it independently so the agreement between them can be quoted.
  2. The paraphrases are one author's guess. Real retry pairs come out of a real planner recovering from a real crash. How such a planner actually rewords a request is an empirical fact this corpus does not have.
  3. One domain, 213 pairs. Flight booking, and nothing else. Nothing here supports a claim about semantic idempotency in general.
  4. Picking the best threshold off this chart is cheating. Choosing τ by the F1 it scored on the very pairs it is being judged on is selection on the test set. A threshold to ship has to be chosen on a held-out split.
  5. The latency column excludes the model. Embeddings are cached on disk, so after the first pass a check reads a vector from a local file instead of calling the encoder. The cost of one real encoder call is reported separately above.
